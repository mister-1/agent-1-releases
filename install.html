ติดตั้งครั้งแรก

ใช้เวลาราว 15 นาที · ปลดล็อกความปลอดภัยแค่ครั้งแรกครั้งเดียว รุ่นต่อไปไม่ต้องทำซ้ำ

ดาวน์โหลดสำหรับ Windows
Agent-1-Setup.exe · ~165 MB · Windows 10/11 (64-bit)

ก่อนเริ่ม: เครื่องต้องมี Chrome หรือ Edge · แรม 8 GB ขึ้นไป · พื้นที่ว่าง 5 GB · และต้องต่อเน็ตตอนกรอก License Key

1

ถ้าเบราว์เซอร์เตือนตอนโหลด ให้กดเก็บไฟล์ไว้

Chrome: กดลูกศรข้างชื่อไฟล์ในแถบดาวน์โหลด → Keep → ถ้าถามซ้ำเลือก Keep anyway

Edge: กดจุดสามจุดที่รายการดาวน์โหลด → เก็บไว้ → แสดงเพิ่มเติม → เก็บไว้อยู่ดี

2

ดับเบิลคลิกไฟล์ → เจอจอสีฟ้า ให้กด More info ก่อน

จอ “Windows protected your PC” ขึ้นมาแบบมีปุ่มเดียวคือ Don’t run — กดคำว่า More info ที่อยู่ใต้ข้อความก่อน แล้วปุ่ม Run anyway จะโผล่ขึ้นมา กดปุ่มนั้นได้เลย

ไม่ใช่ไวรัส — Windows เตือนไฟล์ที่ยังไม่มี “ชื่อเสียงสะสม” กับ Microsoft ทุกไฟล์ ตัวติดตั้งของเราไม่ได้ซื้อใบรับรองราคาหลักหมื่นบาทต่อปีจึงโดนเตือนเป็นปกติ

3

กดผ่านตัวติดตั้งไปได้เลย

หน้าถามที่ติดตั้งกด Next ผ่านได้ · ติดตั้งเฉพาะผู้ใช้ที่ล็อกอินอยู่ ไม่ต้องใช้รหัสผู้ดูแลเครื่อง · เสร็จแล้วจะมีไอคอน Agent-1 บนเดสก์ท็อป

4

เปิดแอปครั้งแรก ไฟร์วอลล์จะเด้ง ให้กด Allow access

ติ๊ก Private networks แล้วกด Allow access — จำเป็นถ้าจะสั่งงานจากมือถือในวง Wi-Fi เดียวกัน (กด Cancel ไปแอปยังใช้บนเครื่องได้ปกติ)

กรอก License Key

ติดตั้งไม่ผ่าน? เปิดดูสองอาการนี้ ⌄

ก. ขึ้นว่า “Smart App Control blocked an untrusted app”

คนละจอกับจอสีฟ้าในขั้นที่ 2 และ ไม่มีปุ่ม Run anyway ให้กดผ่าน — ทางเดียวคือปิดมันก่อนติดตั้ง

  1. พิมพ์ค้นหาที่ปุ่ม Start ว่า Windows Security
  2. ไปที่ App & browser control → Smart App Control settings
  3. เปลี่ยนเป็น Off แล้วกลับมาดับเบิลคลิกตัวติดตั้งอีกครั้ง

ต้องรู้ก่อนกดปิด: ปิดแล้วเปิดกลับไม่ได้อีกเลยนอกจากล้างเครื่องลง Windows ใหม่ (ข้อจำกัดของ Microsoft เอง ไม่ใช่ของแอปนี้) ปิดไปแล้วเครื่องยังปลอดภัยระดับเดียวกับ Windows รุ่นก่อนหน้าที่ยังไม่มีฟีเจอร์นี้

ข. โหลดเสร็จแล้วหาไฟล์ไม่เจอ หรือกดแล้วไม่มีอะไรเกิดขึ้น

แอนตี้ไวรัสลบทิ้งเงียบ ๆ — เปิด Windows Security → Virus & threat protection → Protection history → หารายการ Agent-1 → กด Restore
ยี่ห้ออื่น (Avast, AVG, Kaspersky ฯลฯ) ให้หาเมนู “Quarantine / กักกัน” แล้วกู้คืนเหมือนกัน

เช็กก่อนโหลด: ต้องเป็น Mac ชิป Apple (M1 ขึ้นไป) เท่านั้น
กดโลโก้แอปเปิลมุมซ้ายบนสุด → About This Mac → ดูบรรทัด Chip ต้องขึ้น M1 / M2 / M3 / M4 — Mac ชิป Intel ยังไม่รองรับ ติดตั้งไปก็เปิดไม่ขึ้น
ดาวน์โหลดสำหรับ Mac
Agent-1-macOS-Apple-Silicon.dmg · ~185 MB

ก่อนเริ่ม: เครื่องต้องมี Chrome หรือ Edge · แรม 8 GB ขึ้นไป · พื้นที่ว่าง 5 GB · และต้องต่อเน็ตตอนกรอก License Key

1

ดับเบิลคลิกไฟล์ .dmg แล้วลากแอปไป Applications

หน้าต่างที่เปิดขึ้นมามีไอคอน Agent-1 กับทางลัดโฟลเดอร์ Applications อยู่คู่กัน ลากไปวางทับได้เลย

ในหน้าต่างเดียวกันมีไฟล์ HOW_TO_OPEN_MAC.md แนบไว้ให้ด้วย เนื้อหาเดียวกับขั้นที่ 2

2

เปิดครั้งแรก — ห้ามดับเบิลคลิก

ไปที่โฟลเดอร์ Applications → คลิกขวา (หรือกด Control ค้างแล้วคลิก) ที่ไอคอน Agent-1 → เลือก เปิด → มีกล่องเตือนขึ้นมา กด เปิด ซ้ำอีกครั้ง

ครั้งต่อไปดับเบิลคลิกได้ตามปกติ — ทำแบบนี้ครั้งเดียวจบ

ดับเบิลคลิกตรง ๆ จะโดน Gatekeeper ปิดประตูใส่แบบไม่มีปุ่มให้กดผ่าน เพราะแอปไม่ได้เซ็นด้วยบัญชี Apple Developer — การคลิกขวาแล้วเลือกเปิดคือทางที่ Apple เปิดไว้ให้อนุญาตเอง

3

ถ้า macOS ถามเรื่องการเชื่อมต่อเข้าเครื่อง ให้กด Allow

กล่อง “Do you want the application to accept incoming network connections?” — กด Allow จำเป็นถ้าจะสั่งงานจากมือถือในวง Wi-Fi เดียวกัน (เครื่องที่ปิดไฟร์วอลล์ไว้จะไม่เจอกล่องนี้เลย)

กรอก License Key

ดูวิธีในหัวข้อ “เปิดแอปครั้งแรก” ด้านล่างสุดของหน้านี้

เปิดแอปไม่ได้? เปิดดูสองอาการนี้ ⌄

ก. ขึ้นว่า “Agent-1 is damaged and can’t be opened”

เปิดแอป Terminal วางคำสั่งนี้ กด Enter แล้วลองเปิดแอปใหม่

xattr -cr /Applications/Agent-1.app

ข. คลิกขวาแล้วไม่มีคำว่า “เปิด” ให้เลือก

เข้า System Settings → Privacy & Security → เลื่อนลงจนเห็นบรรทัด “Agent-1 was blocked…” → กด Open Anyway → ยืนยันอีกครั้ง

เปิดแอปครั้งแรก

กรอก License Key ที่ได้รับ แล้วกด “เปิดใช้งาน” — แอปจะพามาหน้านี้เอง ทุกหน้าอื่นถูกล็อกไว้จนกว่าจะเปิดใช้งานสำเร็จ ไม่ใช่แอปเสีย

หน้าจริงที่เจอตอนเปิดแอปครั้งแรก

ขึ้นว่า “ที่นั่งเต็ม” = คีย์นี้ถูกใช้กับเครื่องอื่นครบแล้ว — กรอกอีเมลที่ใช้ซื้อ กด “ดูรายการเครื่อง” แล้วปลดเครื่องเก่าออกเองได้ทันที ไม่ต้องรอผู้ขาย

ขึ้นว่าต่อเน็ตไม่ได้ = ปัญหาอยู่ที่อินเทอร์เน็ต ไม่ใช่ที่ใบอนุญาต — อย่ากรอกคีย์ซ้ำ ให้กด “ลองเชื่อมต่ออีกครั้ง” เมื่อเน็ตกลับมา

แล้วระบบจะพาตั้งค่าต่ออีก 4 ขั้นในหน้าเดียวกัน

  • คีย์ AIวางคีย์ (Anthropic / OpenAI / Google / xAI) แล้วกด “ทดสอบ” ต้องขึ้น “ใช้งานได้”
  • บัญชีผลิตคลิปล็อกอิน Google Flow หรือ Meta AI หนึ่งครั้ง แล้วกด “ตรวจการล็อกอิน”
  • ช่องแรกชื่อช่อง + “ช่องนี้เกี่ยวกับอะไร แนวไหน”
  • ขายของบัญชี Shopee / Lazada — ข้ามได้ถ้ายังไม่ขายสินค้า
ปิดหน้าต่าง ≠ ปิดโปรแกรม แอปเดินเบื้องหลังต่อให้คิวงานและการโพสต์ตามเวลาทำงาน จะปิดจริงสั่ง “ออกจากโปรแกรม” จากไอคอนข้างนาฬิกา (Mac: แถบเมนูด้านบน)
ข้อมูลไม่ได้อยู่ในตัวแอป ถอนแล้วลงใหม่ ข้อมูลเดิมยังอยู่ครบ — Windows เก็บที่ AppData\Roaming\Agent-1 · Mac ที่ ~/Library/Application Support/Agent-1
รุ่นต่อไปไม่ต้องปลดล็อกซ้ำ Windows อัปเดตตัวเองจากในโปรแกรม · Mac โหลด .dmg ใหม่มาลากทับเอง
อยากดูลำดับตั้งค่าทั้งหมดตั้งแต่ต้นจนปล่อยให้ระบบเดินเอง → คู่มือฉบับเต็ม 12 ขั้น
