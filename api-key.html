ขอคีย์ Google AI (ฟรี)

ใช้เวลาราว 3 นาที · ทำครั้งเดียวจบ · ใช้กับขั้น 2 “วางคีย์ AI หนึ่งใบ” ในแอป Agent-1

บัญชี Gmail ส่วนตัวใช้บัญชีที่มีอยู่ได้เลย ไม่ใช่บัญชีบริษัท/โรงเรียน
ทำบนคอมเครื่องที่ลงแอปจะได้กดคัดลอกแล้ววางในแอปได้ทันที
ไม่ต้องผูกบัตรเริ่มใช้ฟรีได้เลย (Free tier)
เปิดหน้า Google AI Studio
aistudio.google.com/api-keys

กดปุ่มด้านบน หรือพิมพ์ aistudio.google.com/api-keys ในช่องที่อยู่ของ Chrome แล้วทำตามขั้นข้างล่าง · หน้าเว็บเป็นภาษาอังกฤษ — ชื่อปุ่มในคู่มือนี้เขียนตามที่เห็นบนจอจริง

1

ล็อกอินด้วยบัญชี Google

ถ้ายังไม่ได้ล็อกอิน Google จะพาไปหน้า Sign in ก่อน — ใส่อีเมล Gmail กด Next ใส่รหัสผ่านตามปกติ

เข้าครั้งแรกอาจมีหน้าต่างต้อนรับหรือข้อตกลงการใช้งานเด้งขึ้นมา ให้ติ๊กยอมรับแล้วกด Continue ไปได้เลย

2

กดปุ่ม Create API key มุมขวาบน

จะเห็นหน้าชื่อ API Keys — กดปุ่ม Create API key ที่มุมขวาบนของหน้า

ถ้าไปโผล่หน้าอื่น (เช่น Playground ที่มีช่องพิมพ์แชต) ให้กดเมนู API Keys ทางซ้าย หรือกดปุ่มสีฟ้าด้านบนของหน้านี้อีกครั้ง

3

ตั้งชื่อคีย์ เลือกโปรเจกต์ แล้วกด Create key

Name your key — พิมพ์ชื่ออะไรก็ได้ เช่น Agent-1 (ไว้จำเองว่าคีย์นี้ใช้กับอะไร)

Choose an imported project — เลือก Default Gemini Project ถ้าในรายการว่างหรือไม่มีให้เลือก กดเมนูเดียวกันแล้วเลือก Create project ตั้งชื่ออะไรก็ได้

แล้วกด Create key

4

กดไอคอนคัดลอกที่แถวของคีย์

คีย์ใหม่จะขึ้นเป็นแถวในตาราง — กดไอคอนสี่เหลี่ยมซ้อนกัน (ตัวแรกทางขวาของแถว) ถ้าขึ้นข้อความ Copied to clipboard ด้านล่างแปลว่าคัดลอกแล้ว

ช่อง Billing Tier ขึ้น Free tier = ใช้ฟรี ไม่ต้องกด Set up billing

คีย์นี้เหมือนรหัสผ่าน — อย่าโพสต์ในกลุ่มแชต อย่าแคปจอส่งใคร ถ้าเผลอหลุดไป กด ⋮ ที่แถวนั้นแล้วลบทิ้ง จากนั้นสร้างใบใหม่

5

วางในแอป Agent-1 แล้วกด บันทึกและทดสอบ

กลับมาที่แอป Agent-1 ขั้น “วางคีย์ AI หนึ่งใบ” → คลิกช่อง คีย์ API → กด Ctrl+V (Mac ใช้ ⌘+V)

ป้ายเขียว Google Gemini จะขึ้นเอง → กด บันทึกและทดสอบ → ขึ้นกรอบเขียวแปลว่าเสร็จ กด ไปต่อ ได้เลย

ผ่านขั้นตั้งค่าไปแล้ว? วางได้ที่เมนู เครื่องมือ › API คีย์ผู้ให้บริการ

เสร็จแล้ว! คีย์ถูกเข้ารหัสเก็บไว้ในเครื่องคุณเท่านั้น ไม่ต้องทำขั้นนี้ซ้ำอีก

ติดปัญหา?

เข้าหน้าเว็บแล้วขึ้นว่าใช้ไม่ได้ / ไม่มีปุ่ม Create API key▾

มักเกิดกับบัญชีบริษัทหรือโรงเรียน (ผู้ดูแลระบบปิดไว้) หรือบัญชีที่ตั้งอายุต่ำกว่า 18 ปี — ออกจากระบบแล้วล็อกอินด้วย Gmail ส่วนตัว แทน

ถ้าใช้ Gmail ส่วนตัวแล้วยังไม่ได้ ลองเปิดหน้าต่างไม่ระบุตัวตน (Ctrl+Shift+N) แล้วล็อกอินบัญชีเดียวในหน้านั้น — กรณีล็อกอินหลายบัญชีพร้อมกัน หน้าเว็บอาจไปเปิดด้วยบัญชีที่ไม่ได้ตั้งใจ

ช่องเลือกโปรเจกต์ว่าง ไม่มีอะไรให้เลือก▾

กดเมนูเลือกโปรเจกต์แล้วเลือก Create project ตั้งชื่ออะไรก็ได้ เช่น Agent-1 → กดสร้าง แล้วเลือกโปรเจกต์นั้นในช่องเดิม

วางในแอปแล้วขึ้นป้ายส้ม “ไม่รู้จักรูปแบบคีย์นี้”▾

แปลว่าคัดลอกมาไม่ครบหรือติดอย่างอื่นมาด้วย คีย์ของ Google ขึ้นต้นด้วย AIza ยาวราว 39 ตัว ไม่มีเว้นวรรค — ลบในช่องให้ว่าง แล้วกลับไปกดไอคอนคัดลอกที่หน้า API Keys ใหม่ (อย่าลากคลุมตัวหนังสือเอง เพราะตารางแสดงแค่ท้ายคีย์)

ทดสอบแล้วขึ้นว่าเกินโควตา / ใช้ไม่ได้ชั่วคราว▾

คีย์ฟรีมีเพดานจำนวนครั้งต่อนาทีและต่อวัน ถ้าเพิ่งสร้างคีย์ รอสัก 1-2 นาทีแล้วกดทดสอบใหม่ คีย์ยังถูกบันทึกไว้แล้ว ทดสอบซ้ำได้ที่ เครื่องมือ › API คีย์ผู้ให้บริการ

ถ้าใช้งานจริงแล้วชนเพดานบ่อย ค่อยกด Set up billing ที่แถวของคีย์เพื่อผูกบัตรกับ Google เอง — จ่ายตามที่ใช้จริง ดูยอดได้ที่ เครื่องมือ › การใช้งาน API ในแอป (ขั้นนี้ไม่บังคับ)

ใช้คีย์ใบเดียวกับหลายเครื่องได้ไหม▾

ได้ แต่ทุกเครื่องจะแชร์เพดานฟรีก้อนเดียวกัน — ถ้ามีหลายเครื่อง แนะนำสร้างคีย์แยกเครื่องละใบ (กด Create API key ซ้ำได้เลย ตั้งชื่อต่างกัน)
