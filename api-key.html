ขึ้นกรอบสีเขียว = เสร็จแล้ว

กด ไปต่อ ในแอปได้เลย คีย์ถูกเข้ารหัสเก็บไว้ในเครื่องคุณ ไม่ต้องทำขั้นนี้ซ้ำอีก

ติดปัญหา?

วางคีย์แล้วขึ้นป้ายส้ม “ไม่รู้จักรูปแบบคีย์นี้”

คีย์ของ Google แบบใหม่ขึ้นต้นด้วย AQ. — แอป Agent-1 รุ่นก่อน 0.156.3 ยังไม่รู้จักรูปแบบนี้ แต่คีย์ใช้ได้ปกติ

วิธีแก้: กด “ขั้นสูง: เลือกผู้ให้บริการเอง” ใต้ช่องคีย์ → ช่องผู้ให้บริการเลือก Google Gemini → กด บันทึกและทดสอบ · หรืออัปเดตแอปเป็นรุ่นล่าสุดแล้ววางใหม่

ถ้าคีย์ไม่ได้ขึ้นต้นด้วย AQ. หรือ AIza แปลว่าคัดลอกมาไม่ครบ — ลบในช่องให้ว่าง แล้วกลับไปกด Copy key ใหม่

ปุ่ม Create key เป็นสีเทา กดไม่ได้

บัญชียังไม่มีโปรเจกต์ — ทำ ขั้น 6 ก่อน (กดช่อง No Cloud Projects Available → + Create project)

ขึ้นแถบแดงว่า “The request is suspicious”

Google สงสัยว่าไม่ใช่คนกด มักเกิดตอนกดเร็ว ๆ ซ้ำหลายครั้ง หรือเปิดผ่านโปรแกรมอื่นที่ไม่ใช่ Chrome ปกติ

ปิดหน้าต่างนั้น รอสัก 1-2 นาที แล้วทำใหม่ใน Chrome ปกติ กดทีละปุ่มช้า ๆ

กดรูปกุญแจแล้วไม่เจอ / เข้าเว็บแล้วใช้ไม่ได้

เข้าตรงได้ที่ aistudio.google.com/api-keys · ถ้าขึ้นว่าใช้ไม่ได้ มักเป็นบัญชีบริษัท/โรงเรียน หรือบัญชีที่อายุต่ำกว่า 18 ปี — ใช้ Gmail ส่วนตัว แทน

ทดสอบแล้วขึ้นว่าเกินโควตา

คีย์ฟรีมีเพดานจำนวนครั้งต่อนาที/ต่อวัน — รอ 1-2 นาทีแล้วกดทดสอบใหม่ที่ เครื่องมือ › API คีย์ผู้ให้บริการ (คีย์บันทึกไว้แล้ว)

ถ้าใช้งานจริงแล้วชนเพดานบ่อย ค่อยกด Set up billing ที่หน้า API Keys เพื่อผูกบัตรกับ Google เอง (ไม่บังคับ)

เผลอส่งคีย์ให้คนอื่น / อยากเปลี่ยนคีย์

หน้า API Keys กดที่แถวของคีย์ → Delete key แล้วสร้างใบใหม่ตามขั้น 5–9 จากนั้นวางใบใหม่ในแอปแทน
