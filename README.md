**[คู่มือฉบับเต็ม 12 ขั้น (ตั้งค่าหลังติดตั้งจนเริ่มผลิตคลิป)](https://agent1-app.pages.dev/)** · **[ยังไม่มี License Key? ลงทะเบียนที่นี่](https://agent1-app.pages.dev/register)**

## ติดตั้งครั้งแรกบน Windows

### 1. โหลดตัวติดตั้ง
กด [Agent-1-Setup.exe](https://github.com/mister-1/agent-1-releases/releases/latest/download/Agent-1-Setup.exe) ในตารางด้านบน ได้ไฟล์เดียวที่ใช้ได้กับ Windows 10 และ 11 ทุกเครื่อง ไม่ต้องเลือกรุ่นอะไรเพิ่ม

### 2. ถ้าเบราว์เซอร์บล็อกตั้งแต่ตอนโหลด ให้กดเก็บไฟล์ไว้
ขึ้นว่า *"ไม่สามารถดาวน์โหลดได้อย่างปลอดภัย"* หรือ *"…is not commonly downloaded"* พร้อมปุ่มลบทิ้ง

- **Chrome** — กดลูกศร `⌄` ข้างชื่อไฟล์ในแถบดาวน์โหลด → **Keep** → ถ้าถามซ้ำเลือก **Keep anyway**
- **Edge** — กดจุดสามจุด `…` ที่รายการดาวน์โหลด → **เก็บไว้** → **แสดงเพิ่มเติม** → **เก็บไว้อยู่ดี**

### 3. ดับเบิลคลิกไฟล์ → เจอจอสีฟ้า ให้กด More info ก่อน
จอ **"Windows protected your PC"** ขึ้นมาแบบมีปุ่มเดียวคือ *Don't run*

1. กดคำว่า **More info** ที่อยู่ใต้ข้อความ
2. ปุ่ม **Run anyway** จะโผล่ขึ้นมา — กดปุ่มนั้น

> **ไม่ใช่ไวรัส** — Windows กันไฟล์ที่ยังไม่มี "ชื่อเสียงสะสม" กับ Microsoft ไว้ก่อนเสมอ
> ตัวติดตั้งของเราไม่ได้เซ็นด้วยใบรับรองราคาหลักหมื่นบาทต่อปี จึงโดนเตือนเป็นปกติทุกเครื่อง

### 4. กดผ่านตัวติดตั้งไปได้เลย
- หน้าถามที่ติดตั้ง กด Next ผ่านได้ ค่าปริยายคือ `C:\Users\<ชื่อผู้ใช้>\AppData\Local\Programs\Agent-1`
- ติดตั้งเฉพาะผู้ใช้ที่ล็อกอินอยู่ — **ไม่ต้องใช้รหัสผู้ดูแลเครื่อง**
- เสร็จแล้วจะมีไอคอน Agent-1 บนเดสก์ท็อป

### 5. เปิดแอปครั้งแรก ไฟร์วอลล์จะเด้ง ให้กด Allow access
กล่อง *"Windows Defender Firewall has blocked some features of this app"* — ติ๊ก **Private networks** แล้วกด **Allow access**
จำเป็นถ้าจะสั่งงานจากมือถือในวง Wi-Fi เดียวกัน (กด Cancel ไปแอปยังใช้บนเครื่องได้ปกติ)

### 6. กรอก License Key
ข้ามไปหัวข้อ [เปิดแอปครั้งแรก](#เปิดแอปครั้งแรก-ทั้งสองระบบ) ด้านล่าง

### เจอสองจอนี้ไม่บ่อย แต่ถ้าเจอจะไปต่อไม่ได้เลย

**ก. "Smart App Control blocked an untrusted app"** — คนละจอกับจอสีฟ้าในข้อ 3 และ **ไม่มีปุ่ม Run anyway ให้กดผ่าน** เพราะ Smart App Control (ของใหม่ใน Windows 11) บล็อกแอปที่ไม่มีใบรับรองชื่อดัง ไม่สนใจว่าผู้ใช้จะยืนยันกี่ครั้ง

1. พิมพ์ค้นหาที่ปุ่ม Start ว่า **Windows Security** แล้วเปิดขึ้นมา
2. ไปที่ **App & browser control** → **Smart App Control settings**
3. เปลี่ยนจาก "On" หรือ "Evaluation" เป็น **Off**
4. กลับมาดับเบิลคลิกตัวติดตั้งอีกครั้ง

> **ต้องรู้ก่อนกดปิด:** ปิด Smart App Control แล้ว **เปิดกลับไม่ได้อีกเลยนอกจากล้างเครื่องลง Windows ใหม่**
> เป็นข้อจำกัดของ Microsoft เอง ไม่ใช่ของแอปนี้ — ปิดไปแล้วเครื่องยังใช้งานปกติ ปลอดภัยระดับเดียวกับ
> Windows รุ่นก่อนหน้าที่ยังไม่มีฟีเจอร์นี้

**ข. โหลดเสร็จแล้วหาไฟล์ไม่เจอ หรือกดแล้วไม่มีอะไรเกิดขึ้น** — โปรแกรมแอนตี้ไวรัสลบทิ้งเงียบ ๆ
เปิด **Windows Security** → **Virus & threat protection** → **Protection history** → หารายการ Agent-1 → กด **Restore**
ยี่ห้ออื่น (Avast, AVG, Kaspersky ฯลฯ) ให้หาเมนู "Quarantine / กักกัน" แล้วกู้คืนเหมือนกัน

## ติดตั้งครั้งแรกบน Mac

ใช้ได้เฉพาะ **เครื่องชิป Apple (M1 / M2 / M3 / M4)** — เช็กที่โลโก้แอปเปิลมุมซ้ายบนสุด → **About This Mac** → ดูบรรทัด **Chip**
Mac ชิป Intel ยังไม่รองรับ ติดตั้งไปก็เปิดไม่ขึ้น

### 1. โหลดตัวติดตั้ง
กด [Agent-1-macOS-Apple-Silicon.dmg](https://github.com/mister-1/agent-1-releases/releases/latest/download/Agent-1-macOS-Apple-Silicon.dmg) ในตารางด้านบน

### 2. ลากแอปไปโฟลเดอร์ Applications
ดับเบิลคลิกไฟล์ `.dmg` → หน้าต่างที่เปิดขึ้นมามีไอคอน Agent-1 กับทางลัดโฟลเดอร์ Applications อยู่คู่กัน ลากไปวางทับได้เลย
(ในหน้าต่างเดียวกันมีไฟล์ `HOW_TO_OPEN_MAC.md` แนบไว้ให้ด้วย เนื้อหาเดียวกับข้อ 3)

### 3. เปิดครั้งแรก — ห้ามดับเบิลคลิก
1. ไปที่โฟลเดอร์ **Applications**
2. **คลิกขวา** (หรือกด Control ค้างแล้วคลิก) ที่ไอคอน Agent-1
3. เลือก **เปิด (Open)**
4. มีกล่องเตือน *"unidentified developer"* ขึ้นมา — กด **เปิด (Open)** ซ้ำอีกครั้ง

**ครั้งต่อไปดับเบิลคลิกได้ตามปกติ** ทำแบบนี้ครั้งเดียวจบ

> ดับเบิลคลิกตรง ๆ จะโดน Gatekeeper ปิดประตูใส่แบบไม่มีปุ่มให้กดผ่าน เพราะแอปไม่ได้เซ็นด้วยบัญชี
> Apple Developer — การคลิกขวาแล้วเลือกเปิดคือทางที่ Apple เปิดไว้ให้อนุญาตเอง

### 4. ยังเปิดไม่ได้? มีสองอาการ แก้คนละทาง

**ขึ้นว่า "Agent-1 is damaged and can't be opened"** — เปิดแอป Terminal วางคำสั่งนี้ กด Enter แล้วลองเปิดแอปใหม่

```
xattr -cr /Applications/Agent-1.app
```

**คลิกขวาแล้วไม่มีคำว่า "เปิด" ให้เลือก** — เข้า **System Settings** → **Privacy & Security** → เลื่อนลงจนเห็นบรรทัด "Agent-1 was blocked…" → กด **Open Anyway** → ยืนยันอีกครั้ง

### 5. ถ้า macOS ถามเรื่องการเชื่อมต่อเข้าเครื่อง ให้กด Allow
กล่อง *"Do you want the application to accept incoming network connections?"* — กด **Allow**
จำเป็นถ้าจะสั่งงานจากมือถือในวง Wi-Fi เดียวกัน (เครื่องที่ปิดไฟร์วอลล์ไว้จะไม่เจอกล่องนี้เลย)

## เปิดแอปครั้งแรก (ทั้งสองระบบ)

**1. กรอก License Key แล้วกด "เปิดใช้งาน"**
แอปจะพามาหน้านี้เอง ทุกหน้าอื่นถูกล็อกไว้จนกว่าจะเปิดใช้งานสำเร็จ — ไม่ใช่แอปเสีย

- ขึ้นว่า **"ที่นั่งเต็ม"** = คีย์นี้ถูกใช้กับเครื่องอื่นครบแล้ว → กรอกอีเมลที่ใช้ซื้อ กด **ดูรายการเครื่อง** แล้วปลดเครื่องเก่าออกเองได้ทันที ไม่ต้องรอผู้ขาย
- ขึ้นว่า **ต่อเน็ตไม่ได้** = ปัญหาอยู่ที่อินเทอร์เน็ต ไม่ใช่ที่ใบอนุญาต → **อย่ากรอกคีย์ซ้ำ** ให้กด "ลองเชื่อมต่ออีกครั้ง" เมื่อเน็ตกลับมา

**2. ทำตามหน้า "ตั้งค่าครั้งแรก" ต่ออีก 4 ขั้นในหน้าเดียวกัน**

| ขั้น | ทำอะไร |
|---|---|
| คีย์ AI | วางคีย์ (Anthropic / OpenAI / Google / xAI) แล้วกด **ทดสอบ** ต้องขึ้น "ใช้งานได้" |
| บัญชีผลิตคลิป | สร้างโปรไฟล์ → ล็อกอิน Google Flow หรือ Meta AI หนึ่งครั้ง → กด **ตรวจการล็อกอิน** |
| ช่องแรก | ชื่อช่อง + "ช่องนี้เกี่ยวกับอะไร แนวไหน" |
| ขายของ | บัญชีนักการตลาด Shopee / Lazada — **ข้ามได้** ถ้ายังไม่ขายสินค้า |

รายละเอียดทุกขั้นพร้อมภาพประกอบอยู่ใน **[คู่มือฉบับเต็ม](https://agent1-app.pages.dev/)**

## สามเรื่องที่ต้องรู้หลังติดตั้ง

**1. กดปิดหน้าต่างไม่ใช่การปิดโปรแกรม** — แอปยังทำงานเบื้องหลังต่อเพื่อให้คิวงานและการโพสต์ตามเวลาเดินต่อได้
จะปิดจริงต้องสั่ง **"ออกจากโปรแกรม"** จากไอคอน Agent-1 บนแถบสถานะ (Windows: ข้างนาฬิกามุมขวาล่าง · Mac: แถบเมนูด้านบน)
ที่เดียวกันนี้สั่งหยุดคิว / เริ่มคิวต่อ / เช็กอัปเดตได้ด้วย

**2. ข้อมูลไม่ได้อยู่ในโฟลเดอร์ที่ติดตั้ง** — ฐานข้อมูล คลิปที่ดาวน์โหลด โปรไฟล์เบราว์เซอร์ และบันทึกการทำงานอยู่ที่

- Windows: `C:\Users\<ชื่อผู้ใช้>\AppData\Roaming\Agent-1`
- Mac: `~/Library/Application Support/Agent-1`

ถอนโปรแกรมแล้วติดตั้งใหม่ ข้อมูลเดิมยังอยู่ครบ

**3. รุ่นถัดไปไม่ต้องปลดล็อกซ้ำ** — ฝั่ง Windows แอปเช็กและอัปเดตตัวเองจากในโปรแกรม ไม่ต้องโหลดตัวติดตั้งมาลงทับอีก
ฝั่ง Mac ยังต้องโหลด `.dmg` รุ่นใหม่มาลากทับเอง

## ถอนการติดตั้ง

**Windows** — สั่ง "ออกจากโปรแกรม" จากไอคอนข้างนาฬิกาก่อน (ถ้าแอปยังเดินอยู่ ตัวถอนจะลบไฟล์ไม่ครบ) แล้วไปที่ **การตั้งค่า → แอป → แอปที่ติดตั้ง** หา Agent-1 แล้วกดถอนการติดตั้ง
**Mac** — ลากไอคอน Agent-1 จากโฟลเดอร์ Applications ไปถังขยะ

ข้อมูลจะไม่ถูกลบไปด้วย ถ้าต้องการลบจริงให้ลบโฟลเดอร์ข้อมูลตามที่อยู่ในข้อ 2 ด้านบนเอง
