Agent-1 · ลงทะเบียนขอใบอนุญาต

กรอกข้อมูลเพื่อรับ License Key

ใช้เวลาไม่ถึง 2 นาที ผู้ดูแลจะตรวจสอบแล้วส่ง License Key ให้ทางช่องทางที่คุณให้ไว้ ระหว่างรอ อ่านคู่มือและดาวน์โหลดตัวติดตั้งเตรียมไว้ได้เลย

✓ ได้รับข้อมูลของคุณแล้ว

ผู้ดูแลจะตรวจสอบและติดต่อกลับพร้อม License Key ทางช่องทางที่คุณให้ไว้

  1. อ่านคู่มือก่อนติดตั้ง — Windows จะเตือนและบล็อกตัวติดตั้ง เป็นเรื่องปกติ ในคู่มือมีวิธีปลดล็อกทีละจอ
  2. ดาวน์โหลดตัวติดตั้งให้ตรงกับเครื่องของคุณ
  3. พอได้ License Key แล้ว เปิดโปรแกรมแล้วกรอก — ทำตามคู่มือขั้นที่ 4 เป็นต้นไป
อ่านคู่มือก่อนติดตั้ง ดาวน์โหลด Windows ดาวน์โหลด Mac (Apple Silicon)

กรอกผิดหรืออยากแก้ข้อมูล? ส่งข้อมูลใหม่อีกครั้ง — ผู้ดูแลจะเห็นทั้งสองครั้งและใช้ครั้งล่าสุด

ข้อมูลของคุณ
ใช้ยืนยันตัวตนเวลาย้ายเครื่อง — ต้องเป็นอีเมลที่คุณเข้าใช้ได้จริง
ชื่อที่โชว์ตอนคุณทักมาทาง LINE หรือ Facebook — ให้ผู้ดูแลจับคู่กับแชทได้ถูกคน
ช่องทางติดต่อ ผู้ดูแลจะส่ง License Key ให้ทางนี้
การใช้งาน
รองรับ Windows 10/11 และ Mac ชิป M1 ขึ้นไป — Mac ชิป Intel ยังไม่รองรับ

ข้อมูลนี้ใช้เพื่อออกใบอนุญาตและติดต่อเรื่องการใช้งาน Agent-1 เท่านั้น ไม่ส่งต่อให้ใคร และไม่ใช้ส่งโฆษณา — แจ้งผู้ดูแลได้ทุกเมื่อถ้าต้องการให้ลบข้อมูล

มีใบอนุญาตอยู่แล้ว? ไม่ต้องกรอกใหม่ — เปิดโปรแกรมแล้วกรอก License Key เดิมได้เลย คู่มือเริ่มต้นใช้งานฉบับเต็ม
